# 🎰 YTRoulette

spin a wheel. get a random youtube search. profit??

## what even is this

you know how old phones/cameras/gopros just dump files with names like `MOV_0042` or `DSC_1337`? yeah. this thing spins a lil wheel, picks a random one of those prefixes, slaps a random 4-digit number on it, and searches YouTube for it in quotes.

sometimes you get nothing. sometimes you get someone's unlisted vacation video from 2011. it's a gamble. it's a *roulette*. hence the name, genius.

100% inspired by [KVN AUST](https://www.youtube.com/@KVNAUST)'s "YouTube Recycle Bin" research

## "features"

- 🎡 a wheel that spins

## how it actually works (for the nerds)

```
click spin → wheel spins (or doesn't, if FAST MODE) → 
random prefix picked from a tiny list → 
random 4 digits slapped on → 
new tab opens with a quoted youtube search
```
